# Hub de Inovação PDI GT

Site responsivo do Hub de Inovação PDI GT, com páginas para as áreas de Geração e Transmissão, artigos e a iniciativa de Hidrogênio Verde, além do envio de ideias. O layout usa conteúdo original, linguagem clara e uma paleta inspirada nas diretrizes visuais fornecidas. Os arquivos em `assets` incluem a logo e imagens fornecidas para a página, conforme autorização informada, além do recorte circular utilizado no destaque. A seção de ideias direciona ao formulário externo do Microsoft Forms.

## Visualizar localmente

Abra `index.html` em um navegador. As páginas `artigos.html` e `projeto-hidrogenio-verde.html` e a folha `inner-pages.css` devem permanecer na mesma pasta. O site não precisa de dependências para exibir o layout.

## Publicar atualizações

O repositório público é [Hub_de_Inovacao_PDI_GT](https://github.com/MariaUngaroSgridd/Hub_de_Inovacao_PDI_GT), e o GitHub Pages publica a partir da branch principal e da pasta raiz. Para publicar uma versão atualizada, envie `index.html`, `artigos.html`, `projeto-hidrogenio-verde.html`, `inner-pages.css` e a pasta `assets` para essa raiz e confira a implantação em **Actions → pages build and deployment**.

Os artigos do projeto de Hidrogênio Verde são organizados por projeto e incluem links para leitura dos cinco PDFs integrais fornecidos, na pasta `assets`. O DOCX recebido sobre hubs industriais é apenas um resumo, não um artigo completo.
